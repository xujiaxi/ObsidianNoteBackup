# Binary Search 模板指南

> 来源：Blind 75 专题精讲
> 核心：**二分法的精髓不是"找到答案"，而是"排除掉一半绝对不可能是答案的区间"**

## 模板选择

| 场景 | while 条件 | 指针更新 | 返回 | 直觉 |
|------|-----------|---------|------|------|
| 找特定 Target | `left <= right` | `mid + 1` / `mid - 1` | 循环内 `return mid`，外 `return -1` | "只要还有一个数没看就不放弃" |
| 找极值/边界 | `left < right` | `mid + 1` / `mid` | 循环外 `return left` | "收缩到左右重合，那个点就是答案" |

## 核心决策逻辑

### left = mid + 1 vs right = mid
- **`left = mid + 1`**: 100% 确定 mid **不是**答案，直接跳过
- **`right = mid`**: 答案可能在左边，**mid 本身可能是答案**，不能丢掉
- **`right = mid - 1`**: 确定 mid 不是答案，配合 `while (left <= right)` 使用

### 旋转数组的特有直觉
- 右边界 `nums[right]` 永远属于"小段升序"的末尾
- 比较 `nums[mid]` 和 `nums[right]` 可直接判断 mid 在高位段还是低位段，**消除二义性**
- 用左边界 `nums[left]` 判断会有**二义性**（无法区分数组是否旋转过）

## 防坑指南

- **溢出防护**: 永远用 `mid = left + (right - left) / 2`
- **死循环**: `while (left < right)` 配合 `right = mid` 时，mid 不能向上取整
- **只有两个元素时**: `nums[left] <= nums[mid]` 用 `<=` 确保归入"左边有序"

## 排除法思维
```
找到有序的那一半 → 检查 target 是否在其中
→ 在：去那一半找
→ 不在：去另一半（含断层的那一半）找
```
